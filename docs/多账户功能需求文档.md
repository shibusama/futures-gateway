> 项目：期界 · 期货交易终端（多账户演示版）
> 文件：`futures-trading-demo.html`（单文件，双击即开，无需 Node/联网）

## 一、需求背景

使用人是一位**基金经理**：他管理多个期货账户（CTP 期货），需要在一个界面里同时盯多个账户的权益、持仓、盈亏，而不是在多个软件/窗口之间来回切换。

| 决策项 | 结论 |
|---|---|
| 真实交易 or 原型 | **原型界面**（模拟数据），暂不连真实 CTP |
| 使用人 | **单人使用**（基金经理本人电脑），不做权限管理 |
| 已实现 | **A：多账户聚合看盘** + **单账户模拟下单** |
| 后续规划 | ⏳ C：资金与风控 |
| 运行环境 | 单文件 HTML，浏览器直接打开，无部署依赖 |

## 二、已实现功能（A · 聚合看盘 + 单账户下单）✅

### 2.1 多账户概览页（首页）
- **顶部 4 个大数字**：
  - 总权益（所有账户合计）
  - 日盈亏（今日盈亏合计）
  - 浮动盈亏（未平仓盈亏合计）
  - 占用保证金（合计）
- **账户列表**：每个账户一行，展示
  - 账户名称、账户号、期货公司
  - 权益、可用资金、浮动盈亏、保证金、持仓手数、日盈亏
  - 提供「删除」按钮
- **按品种汇总**（跨账户合并）：同一品种在所有账户中的
  - 多头手数、空头手数、净持仓、浮动盈亏 —— 方便看全盘总敞口
- **添加账户**：「＋ 添加账户」弹出表单，支持自定义
  - 账户名称 / 账户号 / 期货公司 / 初始资金
- 页面底部有「路线图」备注，明示本期范围与规划中功能

### 2.2 账户明细页（点账户行下钻）
- 点击概览页某账户 → 进入该账户明细，顶部显示该账户名称/账户号/期货公司及资金指标
- 复用原有终端界面：
  - 行情列表（8 个品种实时跳动，可点选切换）
  - K线图（1分/5分/日线切换、MA5/MA10、成交量、悬停读数）
  - 五档盘口（买五卖五）
  - 持仓列表、委托列表（仅展示该账户数据）
- **下单面板可用（模拟撮合）**：买入开多/卖出开空、市价/限价委托，行情跳动驱动实时盈亏

### 2.3 数据与持久化
- 内置 4 个模拟账户（稳健一号 / 进取二号 / 量化三号 / 趋势四号），持仓、盈亏各异，且故意存在**同一品种分布于多个账户**的情况，用于演示按品种合并
- 行情每秒跳动一次；账户日盈亏随之小幅波动
- 账户列表、持仓、委托、当前选中账户**存 localStorage**，刷新页面后保留（无痕模式下不保留）

## 六、技术备注（供后续开发）

- 单文件实现：HTML + CSS + JS（无框架、无构建步骤）
- 持久化 key：`ftd2`（JSON：accounts / activeAcct / view）
- 账户对象结构：
  ```js
  {
    id, name, code, broker, initial,
    realized,        // 累计已实现盈亏
    todayPnl,        // 今日盈亏（模拟波动）
    positions: [{ id, symbol, side: 'long'|'short', lots, avgPrice }],
    orders:   [{ id, symbol, side: 'buy'|'sell', lots, price, status: '已成交'|'已挂单'|'已撤销', time, fillPrice }]
  }
  ```
- 财务口径：
  - 浮动盈亏 = Σ (现价 − 开仓价) × 手数 × 合约乘数 × 方向(多1/空−1)
  - 权益 = 初始资金 + 已实现盈亏 + 今日盈亏 + 浮动盈亏
  - 可用资金 = 权益 − 占用保证金
  - 开仓需校验：所需保证金 = 价格 × 手数 × 合约乘数 × 保证金率 ≤ 可用资金
- 撮合规则：
  - 买入：先平空头（实现盈亏），剩余开多；卖出：先平多头，剩余开空
  - 同向多次开仓按加权均价合并持仓
  - 限价单：买价 ≥ 现价 或 卖价 ≤ 现价 时，行情 tick 后自动成交
- 全局行情共享：同一品种价格对所有账户一致（符合真实期货市场特征）
